# `WAV` Files

> `wav`：波形音频文件格式。
>
> 音质好：大多采用 `PCM` 编码，基本就是“原样”记录声音，几乎无损失。
>
> 体积大：因为没怎么压缩，同样时长下，比 `MP3、AAC` 等格式大很多。
>
> 标准 `WAV`（`PCM` 编码）本质上就是把声波按固定时间间隔采样、量化后直接存成数字序列

声音是以波的形式传播，波在任何时候都有振幅，波形文件的作用就是直接编码声波的样本。采样的作用是允许通过仅记录波在特定时刻的高度或振幅来数字化这个波。

> 根据数学函数从头开始生成波。例如：正弦波、方波、三角波、锯齿波。

## Python 中生成 `WAV` 文件

1. 定义采样率 `frame_rate`
2. 使用 `tri()` 生成三角波
3. 使用 `encode()` 将振幅转换为 16-bit `PCM` 数据
4. 使用 `note()` 控制音符开始、结束以及淡入淡出
5. 使用 `both()` 将多个声音叠加。
6. 最后通过 `play()` 写入 `WAV` 文件。
