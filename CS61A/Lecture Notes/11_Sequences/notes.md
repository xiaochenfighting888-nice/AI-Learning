# 列表

## 创建列表：用方括号组织元素

```python
digits = [1, 8, 2, 8]
```

- `digits` 是自己起的变量名。
- 列表用 `[]` 表示，元素之间用逗号分隔。
- 元素按顺序排列，可以有重复值。

列表中的元素也可以通过表达式计算得到：

```python
digits = [2 // 2, 2 + 2 + 2 + 2, 2, 2 * 2 * 2]
# 得到 [1, 8, 2, 8]
```

创建这个列表时，会先计算各个元素表达式，列表中保存的是计算得到的值，不是表达式的代码。

## `len`：获取列表的元素个数

```python
digits = [1, 8, 2, 8]

len(digits)  # 4
len([])     # 0：空列表没有元素
```

**`len` 统计的是元素个数。重复出现的元素也分别计数。**

因此，虽然 `8` 出现了两次，这个列表的长度仍然是 `4`。

## 索引：通过位置获取元素

语法：

```python
列表[索引]
```

**Python 列表的索引从 `0` 开始。**

对于 `digits = [1, 8, 2, 8]`：

| 元素位置 | 索引 | 取值表达式  | 结果 |
| :------: | :--: | :---------: | :--: |
| 第 1 个  | `0`  | `digits[0]` | `1`  |
| 第 2 个  | `1`  | `digits[1]` | `8`  |
| 第 3 个  | `2`  | `digits[2]` | `2`  |
| 第 4 个  | `3`  | `digits[3]` | `8`  |

对于非空列表，最后一个元素的非负索引是 `len(列表) - 1`：

```python
digits[len(digits) - 1]  # 8
```

如果索引超出范围，会触发 `IndexError`：

```python
digits[4]  # 越界：这个列表不存在第 5 个元素
```

补充：Python 也支持负数索引，从末尾开始计数：

```python
digits[-1]  # 8：倒数第 1 个元素
digits[-2]  # 2：倒数第 2 个元素
```

## 列表的拼接与重复

### +：拼接两个列表

```python
[2, 7] + [1, 8, 2, 8]
# [2, 7, 1, 8, 2, 8]
```

列表的 `+` 会把两个列表的元素按顺序连接起来。

```python
[1, 2] + [3, 4]
# [1, 2, 3, 4]
```

这里不是把对应位置的数字相加。

### *：将列表中的元素序列重复指定次数

```python
digits = [1, 8, 2, 8]

digits * 2
# [1, 8, 2, 8, 1, 8, 2, 8]
```

这里的 `* 2` 表示把整个元素序列重复两次，不是把每个数字乘以 `2`。

### 组合表达式：先重复，再拼接

```python
[2, 7] + digits * 2
```

因为 `*` 的优先级高于 `+`，所以等价于：

```python
[2, 7] + (digits * 2)
```

先得到重复结果：

```python
digits * 2
# [1, 8, 2, 8, 1, 8, 2, 8]
```

再将 `[2, 7]` 拼到前面，最终得到：

```python
[2, 7, 1, 8, 2, 8, 1, 8, 2, 8]
```

长度为 `2 + 4 × 2 = 10`。

**这里的 `+` 和 `*` 会生成新列表，不会修改原来的 `digits`。**

```python
result = [2, 7] + digits * 2

print(digits)  # [1, 8, 2, 8]
print(result) # [2, 7, 1, 8, 2, 8, 1, 8, 2, 8]
```

## operator：用函数形式表达这些操作

使用前需要导入：

```python
from operator import getitem, add, mul
```

它们与左侧写法的对应关系：

|     常见写法      |       函数形式        |         作用          |
| :---------------: | :-------------------: | :-------------------: |
|    `digits[3]`    | `getitem(digits, 3)`  | 获取索引为 `3` 的元素 |
| `[2, 7] + digits` | `add([2, 7], digits)` |     拼接两个列表      |
|   `digits * 2`    |   `mul(digits, 2)`    | 重复列表中的元素序列  |

完整示例：

```python
from operator import getitem, add, mul

digits = [1, 8, 2, 8]

getitem(digits, 3)
# 8

add([2, 7], mul(digits, 2))
# [2, 7, 1, 8, 2, 8, 1, 8, 2, 8]
```

`add` 和 `mul` 表达的是对应的运算操作，具体效果取决于参与运算的对象：

```python
add(2, 3)      # 5：数字加法
add([2], [3])  # [2, 3]：列表拼接

mul(3, 2)      # 6：数字乘法
mul([3], 2)    # [3, 3]：列表重复
```

## 嵌套列表：列表的元素也可以是列表

```python
pairs = [[10, 20], [30, 40]]
```

外层列表包含两个元素，这两个元素本身都是列表：

| 外层索引 | 对应的元素 |
| :------: | :--------: |
|   `0`    | `[10, 20]` |
|   `1`    | `[30, 40]` |

因此：

```python
len(pairs)  # 2：外层只有两个元素

pairs[1]    # [30, 40]
```

### 连续索引：先取外层，再取内层

```python
pairs[1][0]  # 30
```

可以拆成两步理解：

```python
selected = pairs[1]  # 得到 [30, 40]
selected[0]          # 得到 30
```

所以，`pairs[1][0]` 的含义是：

**先取外层的第 2 个元素，再取这个子列表的第 1 个元素。**

类似地：

```python
pairs[0][1]  # 20
pairs[1][1]  # 40
```

注意区分方括号的作用：

- `[10, 20]`：创建列表。
- `pairs[1]`：从已有对象中按索引取值。

## in 与 not in

> 核心：`x in 列表` 判断目标 `x` 是否与列表中的某个直接元素相等。
> 它不会自动深入子列表寻找目标，也不用于判断一段连续元素是否出现。

### in 与 not in 的基本用法

```python
digits = [1, 8, 2, 8]

1 in digits      # True：列表中有整数 1
8 in digits      # True：列表中有整数 8
5 in digits      # False：列表中没有整数 5
5 not in digits  # True：列表中没有整数 5
```

|      表达式      |          判断的问题           |         结果类型         |
| :--------------: | :---------------------------: | :----------------------: |
|   `x in items`   |  `x` 是否在列表 `items` 中？  | 布尔值 `True` 或 `False` |
| `x not in items` | `x` 是否不在列表 `items` 中？ | 布尔值 `True` 或 `False` |

### not in 与 not (...) 的关系

```python
5 not in digits
not (5 in digits)
```

这两种写法的判断结果相同。

因为 `5 in digits` 是 `False`，逻辑取反后就是 `True`。

直接写 `5 not in digits` 更直观。

### 判断的是元素，不是索引

```python
digits = [1, 8, 2, 8]

digits[1]    # 8：取索引为 1 的元素
1 in digits  # True：检查整数 1 是否是列表元素
3 in digits  # False：列表有索引 3，但没有值为 3 的元素
```

|     写法      |            作用             |
| :-----------: | :-------------------------: |
|  `digits[i]`  |    根据索引 `i` 取出元素    |
| `x in digits` | 判断目标值 `x` 是否在列表中 |

```python
digits = [1, 8, 2, 8]

[1, 8] in digits  # False
```

这里的目标是**整个列表 `[1, 8]`**。

而 `digits` 中的直接元素分别是四个整数：

```python
1
8
2
8
```

虽然前两个元素刚好是 `1` 和 `8`，但其中没有任何一个元素本身就是列表 `[1, 8]`。

**列表的 `in` 检查的是成员关系，不是连续子序列关系。**

如果把 `[1, 8]` 作为一个完整元素放进去，结果就不同了：

```python
[1, 8] in [[1, 8], 2, 8]  # True
```

# for 循环与序列解包

> 核心：`for` 每次取出一个元素，把它赋给循环变量，再执行循环体。
> 如果这个元素本身包含多个值，可以直接解包给多个变量。

## for 循环的基本结构

```text
for <name> in <expression>:
    <suite>
```

上面是结构示意，尖括号及其中的文字都是占位说明。

|      部分      |               含义               |
| :------------: | :------------------------------: |
|    `<name>`    | 循环变量，用于接收当前取出的元素 |
| `<expression>` | 表达式，计算结果必须是可迭代对象 |
|   `<suite>`    |  循环体，即每轮执行的缩进代码块  |

可迭代对象可以理解为“能够依次取出元素的对象”，例如列表、字符串、元组和 `range` 对象。

```python
digits = [1, 8, 2, 8]

for digit in digits:
    print(digit)
```

输出：

```text
1
8
2
8
```

这里的 `digit` 依次得到列表中的元素，不是索引 `0、1、2、3`。

`digit` 是自己起的变量名，不需要在循环前预先赋值。

执行步骤：

1. 先计算 `in` 右边的表达式，得到可迭代对象。这个表达式在本次循环开始时求值一次。
2. 取出下一个元素，把循环变量绑定到这个元素。
3. 执行一次循环体。
4. 继续取下一个元素，直到没有更多元素，循环正常结束。

对于列表，会按照元素在列表中的顺序遍历。

```python
for digit in [1, 8, 2, 8]:
    print(digit)
```

## 遍历计数：统计一个值出现多少次

```python
def count(s, value):
    """统计 s 中与 value 相等的元素个数。"""
    total = 0

    for element in s:
        if element == value:
            total = total + 1

    return total
```

调用示例：

```python
digits = [1, 8, 2, 8]

count(digits, 8)  # 2
count(digits, 5)  # 0
count([], 8)      # 0
```

**创建新函数帧的是函数调用；普通 `for`循环本身不会创建新的调用帧。**

## 序列解包：把多个值赋给多个变量

先看普通赋值：

```python
x, y = [1, 2]

print(x)  # 1
print(y)  # 2
```

这叫作**解包（unpacking）**：把右侧的值依次分配给左侧的变量。

解包要求：每次取出的元素要匹配变量个数。

如果列表中的每个元素本身都是包含两个值的序列，就可以直接在 `for` 中解包：

```python
pairs = [[1, 2], [2, 2], [3, 2], [4, 4]]

for x, y in pairs:
    print(x, y)
```

输出：

```text
1 2
2 2
3 2
4 4
```

每轮仍然只从外层列表取出一个元素，然后把这个元素拆给 `x` 和 `y`。

|  轮次   | 从外层取出的元素 | `x`  | `y`  |
| :-----: | :--------------: | :--: | :--: |
| 第 1 轮 |     `[1, 2]`     | `1`  | `2`  |
| 第 2 轮 |     `[2, 2]`     | `2`  | `2`  |
| 第 3 轮 |     `[3, 2]`     | `3`  | `2`  |
| 第 4 轮 |     `[4, 4]`     | `4`  | `4`  |

下面两种写法表达相同的解包过程：

```python
for x, y in pairs:
    print(x, y)
```

```python
for pair in pairs:
    x, y = pair
    print(x, y)
```

**每个内层序列的长度匹配解包变量的个数，不是要求外层列表只能有两个元素。**

# range：整数序列与边界规则

> 核心：`range` 表示按固定步长排列的整数序列，默认步长为 `1`。
> 非空时包含起点，始终不包含终点。

## range 的基本用法

### 三个参数：range(start, stop, step)

`step` 表示每次变化多少，默认为 `1`：

```python
list(range(1, 7, 2))   # [1, 3, 5]
list(range(5, 0, -1))  # [5, 4, 3, 2, 1]
```

- 步长为正时，依次递增，元素必须小于 `stop`。
- 步长为负时，依次递减，元素必须大于 `stop`。
- 无论步长正负，都不包含 `stop`。
- 步长不能为 `0`，否则会触发 `ValueError`。

指定其他步长后，长度不能直接用 `stop - start` 计算：

```python
len(range(1, 7, 2))  # 3，不是 6
```

对于合法的非负索引 `i`，一般的取值公式是：

```text
元素值 = start + i × step
```

### 两个参数：range(start, stop)

默认步长为 `1`。

```python
range(-2, 2)
```

表示从 `-2` 开始，每次增加 `1`，到达 `2` 之前停止。

它包含的元素是：

```text
-2, -1, 0, 1
```

**起点 `-2` 在其中，终点 `2` 不在其中。**

### 一个参数：range(stop)

只传入一个参数时，这个参数是终点，起点默认为 `0`：

```python
range(4) # 与 range(0, 4) 表示相同的序列
```

对应元素：

```text
0, 1, 2, 3
```

## list(range(...))：把 range 转成列表

`range(...)` 得到的是一个 `range` 对象。

使用 `list(...)`，把其中的元素收集成列表，方便查看：

```python
list(range(-2, 2))  # [-2, -1, 0, 1]
list(range(4))      # [0, 1, 2, 3]
```

其中 `list` 是列表构造器，可以从可迭代对象创建列表。

注意两种打印结果的区别：

```python
print(range(4))        # range(0, 4)
print(list(range(4)))  # [0, 1, 2, 3]
```

`range` 不会预先把所有数字保存成一个列表；它可以直接用于遍历，不必先转换成列表。

```text
长度 = 终点 - 起点
```

它适用于**步长为 `1`，且终点大于等于起点**的情况。

例如：

```python
len(range(-2, 2))  # 4，因为 2 - (-2) = 4
len(range(4))      # 4，因为 4 - 0 = 4
len(range(1, 4))   # 3，因为 4 - 1 = 3
```

## 起点大于或等于终点时

```python
list(range(3, 3))  # []
list(range(5, 2))  # []
list(range(0))     # []
```

这些都是空序列，长度为 `0`。

`range(5, 2)` 不会自动改成倒着数。

因此，对于默认步长为 `1` 的 `range(start, stop)`，长度可以写成：

```text
长度 = max(0, stop - start)
```

实际写代码时，直接使用 `len(...)` 即可。

## 按索引取元素

`range` 是序列，也支持索引，索引从 `0` 开始：

```python
r = range(-2, 2)

r[0]  # -2
r[1]  # -1
r[2]  # 0
r[3]  # 1
```

图中的公式：

```text
元素值 = 起点 + 索引
```

适用于**步长为 `1`，且索引是合法的非负整数**的情况。

例如，`r[2]` 的值为：

```text
-2 + 2 = 0
```

补充：`range` 也支持负数索引；超出范围仍会报错。

```python
r[-1]  # 1：最后一个元素
r[4]   # IndexError：不存在索引为 4 的元素
```

# 列表推导式（list comprehension）

基本形式：

```text
[结果表达式 for 变量 in 可迭代对象]
```

带筛选条件的形式：

```text
[结果表达式 for 变量 in 可迭代对象 if 条件]
```

例如：

```python
[x + 1 for x in [1, 3, 5]] # [2, 4, 6]
```

理解时，可以先看 `for` 部分，再看可选的 `if`，最后看最前面的结果表达式。

## 按指定索引取出字母

课件中的列表是：

```python
letters = ['a', 'b', 'c', 'd', 'e', 'f', 'm', 'n', 'o', 'p']

[letters[i] for i in [3, 4, 6, 8]] # ['d', 'e', 'm', 'o']
```

这里遍历的是索引列表 `[3, 4, 6, 8]`，最终收集的是这些索引对应的字母。

可以展开成下面的循环来理解结果生成过程：

```python
result = []

for i in [3, 4, 6, 8]:
    result.append(letters[i])

print(result)  # ['d', 'e', 'm', 'o']
```

`result.append(value)` 表示把一个元素 `value` 添加到列表末尾。

## 只转换：对每个元素加一

```python
odds = [1, 3, 5, 7, 9]

[x + 1 for x in odds] # [2, 4, 6, 8, 10]
```

- `for x in odds`：依次取出 `1、3、5、7、9`。
- `x + 1`：计算每个元素加一后的结果。
- 外层 `[]`：把这些结果收集成新列表。

这里没有筛选条件，所以每个输入元素都会对应一个输出元素。

## 只筛选：保留能整除 25 的元素

```python
odds = [1, 3, 5, 7, 9]

[x for x in odds if 25 % x == 0]
# [1, 5]
```

`25 % x` 是 `25` 除以 `x` 的余数。余数为 `0`，说明 `x` 能整除 `25`，也就是 `x` 是 `25` 的因数。

在 `odds` 中，只有 `1` 和 `5` 满足条件。

- `for` 后面的 `x`：接收当前输入元素。
- 最前面的 `x`：表示把这个元素本身放入结果列表。

## 筛选后转换：先判断，再加一

```python
[x + 1 for x in odds if 25 % x == 0] # [2, 6]
```

对于每个输入元素，先判断 `25 % x == 0`；只有条件成立，才计算 `x + 1` 并加入结果。

展开成普通循环：

```python
result = []

for x in odds:
    if 25 % x == 0:
        result.append(x + 1)

print(result)  # [2, 6]
```

**条件判断使用的是原始的 `x`，不是加一后的结果。**

虽然 `x + 1` 写在最前面，但每轮都先执行筛选，再计算它。

这也不要求先把所有元素筛选完，再统一转换；实际是逐个元素进行“取出、筛选、转换”。
